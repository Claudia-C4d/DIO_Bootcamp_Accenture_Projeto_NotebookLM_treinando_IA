Desafio de Projeto com NotebookLM para o Bootcamp DIO-Accenture

Contexto e Objetivos: 
“Seu Primeiro Pilar da Liberdade Financeira” – Com esse título foi desenvolvido um guia básico para começarmos uma jornada pelo “temido” mercado financeiro, para que qualquer um de nós possa repensar suas atitudes com relação às nossas finanças pessoais, e com a forma com que lidamos com o nosso dinheiro, principalmente porque quase nunca nos preocupamos com o futuro e estamos sempre adiando planos. Esse material, gerado pelo NotebookLM, em meu contato inicial com a ferramenta, além de apresentar de uma forma bem simples e interativa as principais características de investimentos de renda fixa, nos incita a começar agora mesmo um projeto pessoal de investimento financeiro.
